# 风格原则与默认主题

这是一套原创文档插图实现。EvoMap-inspired主题是默认配色选择，不包含或授权任何原始VI手册、Logo、摄影或字体文件；用户提供的第三方参考资料保持在本地，未经许可不随资源包发布。

## 默认主题

默认画布白色不透明，主体黑白灰；蓝强调活动/连接，黄强调关键节点，绿为少量辅助。颜色不独立承担含义：每条主要关系应有位置、形状、箭头或直接标签。

| Token | HEX | 用途 |
|---|---|---|
| paper | #FFFFFF | 画布与白底对象 |
| ink | #000000 | 主要文字 |
| secondary | #53565A | 辅助文字、主要边界 |
| muted | #75787B | 非关键大字，不自动用于小字 |
| line | #D9D9D6 | 辅助边界 |
| surface | #F7F7F6 | 中性浅灰容器 |
| blue | #6EC7E4 | 小面积活动强调 |
| blueStrong | #06CEFC | 活动图形强调 |
| blueTint | #E9F2F4 | 少量活动填色 |
| green | #77F2AE | 辅助完成状态 |
| yellow | #FFD880 | 关键节点 |

默认profile彩色面积宜小于10%。这个约束不用于改变论文原图的科学编码，也不用于替代统计图多系列配色的可访问性检查。

## 布局与可访问性

- 文字与背景保持至少4.5:1对比度；低对比填色需要深色标签和边界。
- 保留圆润节点、清楚连接与外边距。复杂度提高时分页，不删状态或缩小到难以阅读。
- 不让连线穿过文字，不用阴影、渐变或大片高饱和背景掩盖关系。
- 图内只保留解释对象所需的模块、节点、边和状态标签；可见标题/页脚只在明确需要教学页时使用。
- SVG的title/desc提供不可见可访问性说明。PNG固化本次字体；SVG依赖阅读端字体，因此使用font-family回退列表。

## 自定义主题

`--theme file.json`或spec中的`theme`可覆盖colors、fonts、geometry部分，未提供项继承默认。值必须是安全token、六位HEX颜色、字体字符串或有限非负几何值。改变配色后重新检查对比度，不能宣称自定义主题自动具有品牌或色盲安全认证。

如需本机长期主题，保存到`.local/`并在`.local/profile.json`指定`theme_file`；该目录被Git忽略。私有参考文件和认证信息不进入任何公开提交。
